# Team and project setup

The first Northflank flow is less about deployment and more about shaping the workspace correctly.

## What happens first

The onboarding screens show three early actions:

![Northflank onboarding form](/images/northflank-onboarding.png)

- confirm account details
- create or join a team
- choose the first project and plan shape

## Why this matters

Team setup affects how you invite collaborators, connect Git providers, and separate projects over time.

![Northflank team and plan setup](/images/northflank-team-setup.png)

{{% steps %}}

### Complete onboarding

Fill in account basics and accept the required platform terms.

### Create the team

Give the workspace a clear name because it becomes the container for future projects and members.

### Choose the initial plan

Use the free or starter path to validate the workflow, then expand when resource limits become real.

### Create the first project

Pick the deployment target and region based on where the workload should run and how much infrastructure control you need.

{{% /steps %}}

![Northflank project region selection](/images/northflank-region.png)

{{< callout type="warning" >}}
Region choice affects latency, available plans, and in some cases GPU availability. Treat it as an operational decision, not just a form field.
{{< /callout >}}
